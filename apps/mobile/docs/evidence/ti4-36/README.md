# Evidencia visual de TI4-36

Capturas del flujo profesional de acompañamientos, tomadas sobre la aplicación móvil con datos ficticios disponibles en los fixtures actuales.

## Flujo validado

- `listado.png`: listado profesional con Camila Muñoz y Diego Pérez; cada fila conserva identidad, estado y objetivo, y permite abrir el detalle.
- `detalle-permitido.png`: detalle autorizado de Camila Muñoz con objetivo y estado, sin exponer el identificador técnico.
- `detalle-denegado.png`: acceso directo a un acompañamiento de otro profesional; muestra el mensaje genérico de acceso denegado y la acción para volver al listado.

La vista no incorpora agenda, seguimiento, reservas, reportes ni campos que todavía no estén disponibles en el modelo móvil compartido.
