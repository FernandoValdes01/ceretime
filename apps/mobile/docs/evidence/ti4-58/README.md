# Evidencia TI4-58

## Alcance

La pantalla común consume el proveedor de preferencias existente y ofrece una única ruta protegida para los cuatro roles.

La verificación nativa de TalkBack, texto ampliado y persistencia entre roles queda pendiente para una build del SHA final de la PR.

## Procedimiento pendiente

En Android, iniciar sesión con Estudiante, Profesional, Practicante y Administrador, y abrir «Preferencias de accesibilidad» desde el header compartido en cada rol.

Con TalkBack, recorrer los grupos de texto, contraste y movimiento, y comprobar que cada alternativa anuncia su categoría, nombre y estado marcado.

Cambiar cada ajuste, confirmar el resumen efectivo y navegar entre roles; cerrar y volver a abrir la aplicación para comprobar que el valor almacenado se conserva.

Probar el tamaño 100 %, 150 % y 200 %, además de seguir el sistema; verificar que los controles y el acceso del header siguen legibles y alcanzables.

Confirmar que un error de escritura no anuncia éxito y conserva la selección previamente guardada.

Registrar aquí dispositivo, versión de Android, versión de la aplicación, SHA validado, pasos realizados y resultado de cada comprobación antes de cerrar TI4-58.
