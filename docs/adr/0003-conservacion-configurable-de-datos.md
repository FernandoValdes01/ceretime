# Configurar la conservación de los datos

El sistema no fijará en el código un período arbitrario para conservar acompañamientos cerrados. La arquitectura contempla una política configurable definida posteriormente por la UCT y, al vencer el plazo, la eliminación de los datos personales o la anonimización de los necesarios para estadísticas; una obligación legal o un procedimiento abierto podrá suspender temporalmente esa operación. El prototipo no implementará la ejecución automática de esta política y la duración concreta queda pendiente de definición institucional.
