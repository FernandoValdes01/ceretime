# Desarrollar el prototipo sin datos reales

Durante el curso, el equipo desarrollará y demostrará el sistema sólo con datos ficticios o anonimizados. Las pruebas de accesibilidad podrán involucrar personas reales, pero usarán tareas y casos ficticios; cualquier uso con casos reales requerirá autorización institucional, revisión jurídica y controles operativos fuera del alcance del prototipo. Esta separación permite validar la solución sin exponer datos sensibles de estudiantes.
