# Guías de Convex

Estas guías proceden de `get-convex/agent-skills` y conservan sus recursos junto a cada archivo. Son referencias versionadas en el repositorio: la skill principal `../skills/convex/SKILL.md` selecciona cuáles leer y las herramientas no las anuncian como skills independientes.

Para actualizarlas, compara la fuente y sus recursos con los archivos de esta carpeta, conserva las rutas relativas y revisa la skill principal y sus enlaces. No las reinstales en `.agents/skills/`: volverían a aparecer por separado y duplicarían el catálogo. `skills-lock.json` solo registra las skills instaladas, no estas referencias adaptadas.
