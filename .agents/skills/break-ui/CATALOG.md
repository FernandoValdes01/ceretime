# Catálogo de casos límite

Elige solo los casos pertinentes y comprueba sus límites en el contrato. Usa direcciones bajo `example.com` o `.test`.

| Dato | Casos para comprobar |
| --- | --- |
| Nombres | Nombre compuesto largo, nombre de una letra, tildes, apóstrofos, caracteres no latinos y ausencia de nombre cuando se permita. |
| Correo y enlaces | Dirección larga sin espacios, dominio largo y enlaces que deben poder leerse completos. |
| Texto | Títulos y etiquetas largas, saltos de línea, traducciones disponibles y contenido opcional ausente. |
| Números | Cero, uno, cifras grandes, decimales y ausencia de valor; comprueba formato y singular o plural. |
| Listas | Vacía, un elemento, varias filas con datos de distintas longitudes y volumen máximo razonable. |
| Tiempo | Fecha extensa, día o mes de una cifra, zona horaria pertinente y fecha ausente. |
| Imágenes | Sin imagen, error de carga y distintas proporciones, con alternativa accesible. |
| Estados | Carga, vacío, error, éxito y acciones deshabilitadas o pendientes. |
| Entorno | Ancho disponible real, pantalla pequeña, texto ampliado, teclado, lector de pantalla y temas admitidos. |

Comprueba que el contenido se pueda leer, que las acciones sigan disponibles y que los controles no se solapen. Si se recorta información necesaria para distinguir elementos, debe existir una forma accesible de verla completa. Separa lo observado de lo inferido cuando falte una superficie real para probar.
